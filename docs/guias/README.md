# Guías y Runbooks del Repositorio

> **Para qué:** procedimientos y guías paso a paso operativas (instalación, setup de ambiente, scripts de recuperación, troubleshooting).
> **Diferencia con ADR:** un ADR toma una decisión arquitectónica ("por qué"); una guía explica cómo ejecutar un procedimiento paso a paso ("cómo").

Las guías no tienen límite estricto de líneas, pero deben ser directas, prácticas y con comandos listos para ejecutar.
